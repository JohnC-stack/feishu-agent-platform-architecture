# P7 配置管理中心

## 1. 范围与安全边界

配置管理中心用于版本化管理允许列表中的非敏感运行参数。它不替代受保护启动配置：数据库连接串、Redis 地址、监听端口、TLS/mTLS 私钥、飞书 App Secret、GitLab Token、Confluence 密码及其他凭据不得进入 `platform_config_versions.configuration`。

首批在线参数均可在下一次管理快照中生效，无需重启：

| 配置键                          | 默认值 | 允许范围       | 用途                      |
| ------------------------------- | ------ | -------------- | ------------------------- |
| `alerts.queueWaitingThreshold`  | 20     | 1–100000 个    | 队列积压告警              |
| `alerts.budgetPercentThreshold` | 80     | 1–100%         | Token 预算占用告警        |
| `alerts.failedTaskThreshold`    | 1      | 1–10000 个     | 失败任务告警              |
| `alerts.modelFailureThreshold`  | 1      | 1–1000 次      | 模型执行失败严重告警      |
| `health.serviceProbeTimeoutMs`  | 2500   | 250–30000 毫秒 | Windows 服务/集成状态探测 |

任意未知键会被拒绝；键名包含 Secret、Token、密码、凭据、私钥、连接串、证书、Cookie 或 Session 等敏感语义时会返回专用安全错误。值必须是服务端允许范围内的整数。

## 2. 权限与状态机

只有具有 `config.manage` 的 `administrator` 可以校验、创建、更新、发布和回滚配置。页面隐藏不是权限边界，每个写接口都会重新验证 HttpOnly 管理会话和 RBAC。

```text
无版本 ──创建──> 草稿 ──校验/保存──> 已校验草稿 ──精确确认──> 生效
                                                │
历史已替换版本 ──精确确认回滚──────────────────────┘（创建新的生效版本）
```

- 每个版本都有递增版本号和 SHA-256 校验和。
- 已发布版本不可修改；任一时刻最多有一个 `active` 版本。
- 发布会把旧生效版本转为 `superseded`。
- 回滚不会重新启用或改写旧记录，而是复制其已校验配置并创建新的生效版本。
- 创建、更新、发布和回滚均写入脱敏审计，包含操作人、版本号和校验和，不包含凭据。

## 3. 页面操作

1. 使用超级管理员入口登录，进入 **平台运维 → 配置中心**。
2. 若没有草稿，编辑器从当前生效版本或安全默认值开始；填写版本说明和变更摘要。
3. 点击 **校验配置**，确认页面显示“服务端校验通过”。
4. 点击 **创建草稿**；已有草稿时按钮显示为 **更新草稿**。
5. 输入页面给出的精确文本 `发布配置版本:<版本号>`，点击 **发布并即时生效**。
6. 刷新页面，确认唯一生效版本、校验和、启用人和启用时间正确。
7. 需要恢复历史参数时选择 `superseded` 版本，填写原因和精确文本 `回滚配置至版本:<版本号>`；确认系统创建了新的生效版本。

版本差异面板以当前生效版本为基准，只列出发生变化的允许列表参数。受保护启动配置区只显示键名、来源、是否已配置和重启要求，不返回实际值。

## 4. 管理接口

| 方法    | 路径                                           | 作用               |
| ------- | ---------------------------------------------- | ------------------ |
| `POST`  | `/v1/admin/config/validate`                    | 只校验，不写数据库 |
| `POST`  | `/v1/admin/config/versions`                    | 创建已校验草稿     |
| `PATCH` | `/v1/admin/config/versions/:configId`          | 更新现有草稿       |
| `POST`  | `/v1/admin/config/versions/:configId/publish`  | 精确确认后发布     |
| `POST`  | `/v1/admin/config/versions/:configId/rollback` | 精确确认后受控回滚 |

接口请求和响应不得记录配置文件原文以外的环境变量，也不得把凭据内容放入版本说明、变更摘要或确认文本。
